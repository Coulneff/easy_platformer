# easy_platformer
# Установка
СКАЧАЙТЕ ФАЙЛ УСТАНОВКА ПРОГРАММЫ. В файле описано как установить программу для работы в ней. УСТАНОВИТЬ программу необходимо ЗАРАНЕЕ до начала мастер - класса.
# Материалы
В ПАПКЕ "Текстовая инструкция и материалы" - расположены следующие файлы:
- папка "Sprite" в которой находится все графические материалы которые будут необходимы для работы с мастер-классом.
- документ "Practic1.docx" - в котором расписан текстовый вариант мастер-класса который позволит вам двигаться вслед за мастер-классом если вы начнёте неуспевать.
